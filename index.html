OPTIONAL SETUP

Connect your local AI

Use an open-weight model on your own computer with Ollama. No API key or paid AI service required.

  1. 1
    Install Ollama

    Download it from ollama.com.

  2. 2
    Download a modelollama run qwen2.5:3b

    Keep Ollama running while using this app.

  3. 3
    Allow local browser access

    In a terminal, start Ollama with browser access enabled, if needed:

    OLLAMA_ORIGINS=* ollama serveWindows PowerShell: $env:OLLAMA_ORIGINS="*"; ollama serve

If local AI is not connected, the app uses a built-in demo generator so you can still test the interface. Demo output is template-based, not generated by a model.
